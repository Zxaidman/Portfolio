# Design history

Every design the site has shipped. **No repeats:** before a weekly overhaul or monthly rework, read this list (and the snapshots in `design/archive/`) and choose a direction that differs clearly in name, palette, type and layout from every entry. `scripts/portfolio.py validate` enforces part of this: name, font set and paper+accent pairs must not match any archived design.

- **Weekly (MINOR, Mondays):** new design system: palette themes, type, scale, component styling. Snapshot in `design/archive/`.
- **Monthly (MAJOR, the 1st):** complete rework: new concept, layout and interactions, plus a new Claude Design System artifact. Snapshot in `design/archive/`.
