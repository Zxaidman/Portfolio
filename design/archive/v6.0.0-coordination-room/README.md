# Coordination room (v6.0.0)

The page is a BIM coordination control room, the screen wall a site team watches during a federated model review. After the scroll stage the site docks a Revit-style Project Browser on the left (a tree of Views, Sheets, Families and Project information that tracks where you are) and lays everything else out as dockable dashboard panels on a 12-column wall: a live KPI strip counted from the model data, the active view with a properties palette, a model browser of every project with a storey gauge and a sort switch, a bank of site-camera monitors playing the build-ups, a sheet register of the BBS drawings, the families (skill cards), the team, an event log of every revision, and a request panel. A telemetry ticker runs across the top, the clock is live, and the display can be switched between themes. Signature motion: monitor power-on. As each panel scrolls into view it switches on like a control-room screen: a bright phosphor line opens across the middle, the picture opens vertically from it with a brief over-bright flash, then the panel's status LED lights.

Restore by copying these files back to the repo root, then `python3 scripts/portfolio.py build`.
