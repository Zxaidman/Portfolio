# Datum (v7.1.0)

Datum is a surveyor's field atlas for built work: a technical record assembled from setting-out marks, levels, section cuts and site annotations. The existing editorial monograph structure remains intact, but its visual language shifts to the drawing office: a restrained paper-and-graphite base, one deep setting-out indigo datum accent, blueprint and night-shift editions, square registration marks, calibrated rules, compact coordinate metadata and crisp sans-serif typography. Space Grotesk carries headings; IBM Plex Sans handles reading; IBM Plex Mono is reserved for levels, drawing references, dimensions and revision data. The new signature motion is a survey sweep: a thin datum line scans each section heading as it enters the reading field, like a total station establishing a reference line. The motion is CSS view-timeline enhanced, static by default, and disabled under reduced motion. The scroll-stage BIM signature and skill cards remain permanent and read only design tokens.

This immutable snapshot contains the active design system, generated tokens, primary stylesheet, progressive-enhancement JavaScript and renderer.
