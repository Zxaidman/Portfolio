# Bar bending yard (v3.1.0)

The tower is still read roof to foundation, but every surface now comes from the bar bending yard: slabs end on a ribbed TMT bar instead of a flat edge, buttons and chips are punched bar-mark tags, frames have the soft corners of a bent bar (bend radius, not a sharp corner), and headings are forged as they arrive, stretching from a thin, narrow cut length to a heavy, wide bar.

Restore by copying these files back to the repo root, then `python3 scripts/portfolio.py build`.
