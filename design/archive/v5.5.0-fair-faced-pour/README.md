# Fair-faced pour (v5.5.0)

The page is struck from the formwork: fair-faced, off-shutter concrete. The background carries the shutter-ply panel joints and the plugged tie holes you see on an exposed concrete wall, every edge is chamfered like the 20 mm fillet on a column arris (bevelled corners, no round radii), buttons and chips are chamfered pour tags, and headings are set in a tall industrial condensed face like the stencilled grid marks on a slab. Signature motion: pour level. As each panel scrolls into view a concrete level rises through it from the bottom with a bright pour line on top, the way a lift fills a column form, then settles into a construction-joint rule at the top edge.
