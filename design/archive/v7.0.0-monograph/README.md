# Monograph (v7.0.0)

The coordination room is torn down and the portfolio is re-set as a printed monograph: a bound review of built work, typeset like an architectural journal. A masthead carries the publication name, the issue line (volume and number from the version) and a dateline; a Contents index with folio numbers is the navigation, echoed by a slim running-head bar that tracks the section you are reading. The body is an editorial measure: a leader essay opens with a drop cap, Selected Works runs as numbered features with plate figures and figure captions, the build-up films are motion plates, and the reinforcement drawings are a technical appendix. Pull quotes drawn from the work sit in the margin; hairline rules, folios and a colophon frame every page. Type is Bodoni Moda, a high-contrast Didone, for display, Newsreader for the reading measure and its italic pull quotes, and Courier Prime, a typewriter face, for folios, plate numbers and metadata. Signature motion: ink set. As a page enters the measure the display heading prints in left to right through a clipped ink gradient on a view() timeline, figure plates develop up from a halftone dot screen as a register rule is struck beneath them, and the drop cap inks in. Everything is static under reduced motion and without JavaScript.

Restore by copying these files back to the repo root, then `python3 scripts/portfolio.py build`.
