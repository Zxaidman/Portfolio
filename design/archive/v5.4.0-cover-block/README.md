# Cover block (v5.4.0)

The page is detailed like a reinforcement cage before the pour. Every panel is a stirrup: soft bend-radius corners on three sides and a tight hooked corner where the 135-degree hook closes, with a short hook leg drawn past it. Buttons and chips sit on round cover blocks (the concrete spacers that hold bars off the shutter), lists are threaded with tie-wire dots, and headings are set in a soft optical serif like the lettering on a hand-drawn bending schedule. Signature motion: stirrup trace. As each activity and panel scrolls into view, its outline is drawn bar by bar (top leg, side, bottom, side, then the hook) on a CSS view() timeline, the way a detailer draws a stirrup.

Restore by copying these files back to the repo root, then `python3 scripts/portfolio.py build`.
