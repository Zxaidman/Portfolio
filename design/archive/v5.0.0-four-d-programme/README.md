# Four-D programme (v5.0.0)

The portfolio is a 4D construction programme, the way a planner reads a Navisworks TimeLiner or Primavera schedule. A week ruler runs across the top as the navigation, with each section as an activity bar and a red data-date line that slides along as you scroll. Every section opens on an activity row (WBS code, duration, start and finish) whose bar fills as it comes into view. The projects are a Gantt chart: each project is a bar as long as the building is tall. Faint week columns run down the whole page, the featured project sits on the critical path, and the contact section is the handover key date.

Restore by copying these files back to the repo root, then `python3 scripts/portfolio.py build`.
