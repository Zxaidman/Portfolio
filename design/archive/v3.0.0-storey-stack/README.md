# Storey stack (v3.0.0)

The page is a tower in section. You arrive on the roof and descend level by level to the foundation: every section opens on a Revit level datum with its elevation, a lift car in the side shaft tracks where you are, and media is revealed by a section box sweeping open.

Restore by copying these files back to the repo root, then `python3 scripts/portfolio.py build`.

Layout archetype: floor-by-floor stack. Signature motion: section-box clipping reveal.
